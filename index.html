My Work

Mail-Collecting Drone

This custom-built, heavy-lift UAV was designed from scratch to navigate a three-story drop and retrieve mail. The project required independently learning aerodynamics, CAD modeling, and soldering, eventually scaling up to a 6S battery and 14-inch propellers to handle the payload. The hardware features a custom-soldered electronics stack alongside several original 3D-printed components, including landing gear, a Raspberry Pi mount, a payload carrier (for a magnet, camera, and LiDAR), and an elevated GPS mast to prevent electromagnetic interference.

Currently, the drone successfully completes its mail-collecting mission via remote control, stabilized by Ardupilot autotuning and custom gyro filters configured from flight data logs. The ongoing final phase of the project is achieving full autonomy. Using MAVLink communication between the Raspberry Pi and the flight controller, the system will soon integrate GPS, LiDAR, and Arducam data to independently navigate to the mailbox, perform a precision landing using AprilTag computer vision, magnetically retrieve the mail, and autonomously return to base.
